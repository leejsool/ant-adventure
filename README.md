# 개미들의 대모험

알에서 깨어난 아기 개미가 동기 친구들과 함께 굴 밖으로 모험을 떠나는 브라우저 게임입니다.
설치 없이 주소만 열면 컴퓨터와 핸드폰(가로 화면)에서 바로 할 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 이동 |
| Shift | 달리기 |
| 스페이스 | 점프 |
| F | 물기 / 확인 |
| G | 하기 (저장고, 헬스장, 연못, 물거미 숨바꼭질) |
| E | 인벤토리 (Q: 내보내기) |
| V | 굴 밖에서 1인칭 ↔ 3인칭 (X 또는 클릭: 개미산 발사) |

핸드폰은 화면 버튼과 드래그로 움직입니다. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

## 파일

- `index.html` : 게임 본체 (웹에 올리는 판)
- `ant-adventure.html` : 파일 하나로 열리는 판
- `make-single.py` : 위 두 파일과 zip을 다시 만드는 스크립트

저장은 브라우저(localStorage)에 자동으로 되며, 저장 칸은 3개입니다.
- `assets/` : 호텔 크리스마스 그림 조각 (파일 하나 판에는 안에 들어 있음)
